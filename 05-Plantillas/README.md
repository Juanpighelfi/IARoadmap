# Qué plantilla usar

Para registrar el progreso, usá solo [Mi seguimiento](../00-MOC/Estado%20actual.md). La [plantilla vacía](Plantilla%20de%20progreso.md) se copia una vez; después seguís escribiendo en ese mismo archivo.

Para resolver las actividades, abrí las [hojas de ejercicios ya armadas](../08-Ejercicios/README.md). No se crean a partir de estas plantillas ni se completa una ficha técnica adicional si la hoja ya reúne los resultados.

## Opcionales, para una tarea concreta

| Plantilla | Cuándo sirve | Cómo completarla |
| --- | --- | --- |
| [Proyecto](Plantilla%20de%20proyecto.md) | Cuando necesitás explicar una aplicación o experimento | Una frase por apartado y enlaces al código; no duplicar un README que ya lo explica |
| [Evaluación técnica](Plantilla%20de%20evaluacion.md) | Cuando querés comprobar cómo responde un sistema | Escribir entradas de prueba, qué esperás y qué ocurrió; no es una nota sobre tu rendimiento como estudiante |
| [Lectura de paper](Plantilla%20de%20lectura%20de%20paper.md) | Cuando un artículo aporta a una pregunta de tu proyecto | Anotar la idea útil, su límite y qué vas a hacer con ella; no por cada video o página que leés |

No son entregas obligatorias del día a día. Si no estás haciendo esa tarea, no uses esa plantilla. Los archivos antiguos de sesión, semana y módulo solo redirigen al seguimiento único.
