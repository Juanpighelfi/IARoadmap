# Diseño: roadmap personal de IA

## Objetivo y autorización

Aplicar la auditoría aprobada en la conversación del 6 de septiembre de 2026. El usuario pidió aplicar las mejoras a su estudio personal y descartó validaciones con otros estudiantes. La comprobación será individual: ejercicios, rúbricas, transferencia y retención. No requiere nuevas aprobaciones de diseño.

## Alcance

- Conservar los módulos útiles y sus nombres para mantener referencias.
- Incorporar fundamentos de búsqueda y decisión, visión, IA local y robótica.
- Hacer una ruta personal principal, con diagnóstico y un proyecto de inspección visual de piezas; mantener alternativas por objetivo.
- Catálogo único en curriculum.json: módulos, prerrequisitos, horas orientativas y rutas ordenadas. Generar tablas y validar dependencias para evitar contradicciones.
- Separar estado administrativo de dominio demostrado. Progreso privado local, sin inventar horas, hardware, presupuesto ni módulos aprobados.
- Recursos acotados, ejercicios concretos, corrección y recuperación en cada módulo.
- Laboratorios reproducibles sin GPU ni APIs como puerta de entrada. Los proyectos con imágenes/modelos reales requieren datos y entorno propios; no se prometen resultados ficticios.
- Enlaces Markdown relativos compatibles con GitHub y Obsidian. Mantener canvas con ramas claras.
- Comprobaciones automáticas de rutas, enlaces internos, artefactos generados y laboratorios. Comprobación externa optativa para no convertir fallas de red en fallas del material.

## Fuera de alcance

No crear una plataforma web, cuentas de estudiantes, analítica de cohortes ni un curso enciclopédico. No comprar hardware, contratar APIs, activar recordatorios ni registrar progreso por el usuario.

## Aceptación

README conduce a diagnóstico, ruta personal y primer laboratorio. Todas las rutas respetan prerrequisitos. Cada módulo tiene práctica y rúbrica. El calendario explicita horas y profundidad. Las soluciones de referencia pasan pruebas y los ejercicios incorrectos son rechazados. No hay referencias internas rotas. GitHub recibe un cambio atómico basado en la revisión actual, sin sobrescribir trabajo concurrente.
