# Glosario esencial

- AI/IA: campo general de sistemas que realizan tareas asociadas a inteligencia.
- ML: modelos que aprenden patrones desde datos.
- Deep learning: ML basado en redes neuronales profundas.
- GenAI: IA que genera texto, imagen, audio, video o codigo.
- LLM: modelo de lenguaje grande.
- Token: unidad de texto que procesa un modelo.
- Embedding: vector que representa significado o similitud.
- Context window: cantidad de tokens que el modelo puede considerar en una llamada.
- Inference: uso de un modelo entrenado para producir una salida.
- Fine-tuning: ajuste de un modelo con datos propios.
- RAG: retrieval augmented generation; generar respuestas usando documentos recuperados.
- Agent: sistema que usa un modelo para decidir pasos y usar herramientas.
- Tool calling: capacidad de llamar funciones externas con argumentos estructurados.
- Eval: prueba sistematica de calidad, seguridad o comportamiento.
- Hallucination: respuesta no soportada por evidencia o datos reales.
- Prompt injection: intento de manipular instrucciones del sistema mediante contenido externo.
- LLMOps: practicas para desplegar, evaluar y operar sistemas con LLMs.
- MLOps: practicas para desplegar, versionar y monitorear sistemas ML.
- Drift: cambio de datos o comportamiento que degrada un modelo.
- Groundedness: grado en que una respuesta esta apoyada por fuentes recuperadas.
