# Glosario esencial

Definiciones de trabajo. Agregá ejemplos propios de los términos que uses; no hace falta memorizar toda la lista al empezar.

| Término | Significado |
| --- | --- |
| IA | Campo que estudia sistemas capaces de percibir, razonar, aprender o actuar para lograr objetivos |
| ML | Métodos que ajustan su comportamiento a partir de datos o experiencia |
| Deep learning | ML con redes neuronales de múltiples capas |
| Estado / acción | Representación de una situación y decisión disponible en ella |
| Heurística | Estimación que orienta una búsqueda; sus propiedades determinan garantías |
| Restricción | Condición que una solución debe satisfacer |
| MDP | Modelo de decisiones con estados, acciones, transiciones y recompensas |
| Política | Regla que elige acciones según el estado u observación |
| RL | Aprendizaje de políticas a partir de interacción y recompensas |
| Estado oculto | Variable relevante del sistema que no se observa directamente |
| Baseline | Referencia sencilla contra la que comparar una propuesta |
| Leakage | Información no disponible al predecir que entra en entrenamiento o evaluación |
| Validación / test | Datos para elegir decisiones / datos reservados para estimación final |
| Gradiente | Vector de derivadas parciales que indica cambio local de una función |
| Loss | Función usada como objetivo de optimización; no equivale necesariamente a la métrica útil |
| Calibración | Concordancia entre probabilidades predichas y frecuencias observadas |
| Drift | Cambio de distribución; no implica automáticamente degradación, que debe medirse |
| Embedding | Representación vectorial aprendida; su similitud depende del entrenamiento y uso |
| Token | Unidad discreta de representación; en lenguaje puede ser fragmento de texto, byte u otra unidad |
| LLM | Modelo de lenguaje de gran capacidad; no garantiza veracidad |
| Inferencia | Aplicar un modelo ya entrenado a una entrada |
| Fine-tuning | Continuar entrenamiento de un modelo para adaptarlo |
| RAG | Generación apoyada en información recuperada, con evaluación de recuperación y respuesta |
| Groundedness | Grado de apoyo de la respuesta en la evidencia suministrada |
| Agente | Sistema que percibe y elige acciones; un agente LLM es un caso particular |
| Tool calling | Solicitar una función mediante argumentos; la autorización y ejecución corresponden al sistema |
| Eval | Procedimiento de evaluación con casos y criterios definidos |
| Prompt injection | Contenido no confiable que intenta alterar instrucciones o acciones del sistema |
| Cuantización | Representar parámetros o cómputos con menor precisión; su efecto debe medirse |
| Edge | Procesamiento cerca de donde se generan los datos, con restricciones del dispositivo |
| Sim-to-real | Transferencia desde simulación a un sistema físico, que necesita validación adicional |
| Ablación | Experimento que quita o cambia un componente para estudiar su contribución |
