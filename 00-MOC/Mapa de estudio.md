# Mapa de estudio

## Secuencia completa

```text
00 Orientacion
 -> 01 Python, Git y entorno
 -> 01b Ingenieria asistida por IA
 -> 02 Datos, SQL y estadistica
 -> 03 Matematicas para ML
 -> 04 Machine learning clasico
 -> 05 Deep learning y PyTorch
 -> 05b Post-training aplicado
 -> 06 LLMs aplicados
 -> 06b Context engineering
 -> 07 RAG y busqueda
 -> 08 Agentes y workflows
 -> 08b MCP y protocolos de herramientas
 -> 09 Multimodalidad
 -> 10 Evaluacion, seguridad y gobernanza
 -> 10b Error analysis y evals desde trazas
 -> 11 MLOps, LLMOps y despliegue
 -> 11b Inferencia, costos y economia unitaria
 -> 12 Profundizacion
 -> 12b Capa profesional
```

Los niveles con sufijo `b` se agregaron despues de la primera version. No son
opcionales por ser suplementarios: 06b, 08b, 10b y 11b son lo que separa un demo de un
sistema que aguanta usuarios. 01b y 12b son transversales y corren en paralelo.

## Seguimiento

Donde estas se registra en [[00-MOC/Estado actual]] y se actualiza cada semana desde
[[06-Bitacora/Como usar la bitacora]]. Sin eso, esta secuencia es una lista de deseos.
