# Ejercicios listos para completar

Elegí el módulo que estás cursando y abrí su hoja. En Obsidian, usá el modo edición y escribí donde dice «Tu respuesta» o después de cada pregunta. No hace falta crear tablas, aprender Markdown ni instalar un plugin.

**Si estás en 00, abrí [esta hoja](00.md).** Tiene el ejemplo, el prompt y los 14 casos. Continuá desde donde estabas; no reinicies un ejercicio que ya hiciste.

Cada hoja sirve para resolver la actividad una vez. El código, los datos y las capturas se guardan en sus archivos y se enlazan desde la hoja. «Mi seguimiento» solo te recuerda qué hacer después; no copies allí todas las respuestas.

## Guardar el trabajo

Podés editar la hoja directamente en tu copia del repositorio. Como estos archivos forman parte del material versionado, tus respuestas serán cambios locales de Git. Si preferís mantenerlas separadas, duplicá la hoja una vez en `Mi-progreso/` y seguí en esa copia; no hace falta vaciar o reconstruir la estructura. Esa carpeta no se sube con Git y necesita respaldo propio. Antes de actualizar el material, conservá tus respuestas; no descartes cambios de Git para poder hacer pull.

Las hojas de referencia permanecen sin respuestas personales. No se escribieron ni inventaron resultados de tus pruebas.

## Cómo saber cuándo está resuelta

Seguí las condiciones del módulo. Una respuesta escrita no reemplaza ejecutar el código o probar la integración cuando eso forma parte de la actividad. Si no lo ejecutaste, escribí «sin ejecutar». Las variantes y las condiciones técnicas se mantienen; no hay puntajes ni una ficha extra que completar.

Para que te corrija un asistente, compartí la hoja y los archivos o resultados necesarios. No hay otra plataforma de entrega. Podés resolver un apartado por sesión: no hace falta llenar toda la hoja de una vez.
