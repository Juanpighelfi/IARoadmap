# Aplicaciones con LLMs

Ruta aplicada para construir con modelos existentes. Los módulos iniciales se pueden acreditar por diagnóstico; permanecen en la secuencia para hacer explícitas las dependencias.

Proyecto: extractor de especificaciones desde texto, ampliado a consulta de notas y workflow local. Evaluación desde el principio. No exige MCP ni multiagentes. La operación avanzada del módulo 11 requiere sus fundamentos de ML; para una API LLM inicial usá validación, logs, límites y un despliegue local sencillo dentro del proyecto.

Extensiones: 08b si necesitás un servidor MCP, 09 para documentos/audio, 05b después de completar 02–05 si realmente necesitás entrenamiento. No se promete convertirse en experto por completar una lista.
