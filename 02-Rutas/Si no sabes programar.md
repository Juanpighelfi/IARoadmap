# Si no sabes programar

Empezá con [CS50P](https://cs50.harvard.edu/python/) y sus ejercicios de funciones, bucles, archivos y pruebas. La documentación oficial de Python es consulta complementaria. Usá el laboratorio 01 para verificar el entorno y la habilidad, no para memorizar una solución.

La secuencia incluye una base de datos/matemáticas/ML y una primera app LLM. Si tu objetivo inmediato es solo esa app, la ruta developer tiene el recorrido aplicado completo. Los diagnósticos pueden acreditar pasos previos; no los omitas únicamente por experiencia declarada.
